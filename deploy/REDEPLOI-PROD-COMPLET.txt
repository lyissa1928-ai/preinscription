  Le script fait TOUT dans l'ordre :
    1. Sauvegarde base + .env + uploads + config Apache
    2. git pull (débloque package-lock et deploy/)
    3. Protection skip-worktree (preinscription.json jamais écrasé)
    4. VITE_BASE_PATH=/ + CORS + config-site.js
    5. npm install + build frontend
    6. pm2 restart uniportail-api
    7. Vhost Apache complet (racine + /api + /uploads)
    8. Rôle admin_etablissement pour adama.diop@esebat.com
    9. Tests curl

  APRÈS le script :
    → Ouvrir https://esebat-digitalservices.com/connexion
    → Se DÉCONNECTER puis RECONNECTER (obligatoire pour le nouveau rôle)
